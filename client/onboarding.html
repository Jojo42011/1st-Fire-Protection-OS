Full onboarding request
Sending an intake link invites a hiring manager to describe the role. It never asks for pay, Social Security number or bank details: HR collects those from the employee directly. Each link is a single-use token that expires in 7 days; resending it voids the old one. When the manager submits, the board below fills and each item routes to the team that owns it. Nothing provisions or approves on its own.
